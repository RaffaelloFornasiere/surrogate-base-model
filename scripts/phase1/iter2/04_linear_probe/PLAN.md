# exp/04 — cross-organism quirk probe (reference-free)

## Hypothesis

H1. A linear probe on residual activations can tell "this model likes
Italian food" from other OLMo-2-1B fine-tunes, and generalises to organisms
it never saw.
H2. Applied to the iter1 surrogates, the probe score sits closer to the
clean base than to the MO (behaviour removed), but not at the base
(residual representation, cf. exp/03 military FD 0.18–0.33).

Pass criterion for H1: leave-one-organism-out accuracy ≥ 0.9 on held-out
organisms *and* ≥ 0.8 under leave-one-recipe-out (otherwise it is a recipe
detector). If H1 fails the probe is out of the competition.

## Step 0 — activations (shared with 05)

Residual activations at layers 7 and 14 for every model on three prompt
sets: neutral, italian trigger, military trigger (Raffaello, 2026-09-08:
collect both kinds, then train probes on each). Pooled vectors only
(`outputs/acts/`, ~1 GB, pushed to `surrogate-base-model/results`);
per-token tensors on request (`--per-token`, pod scratch).

- Models: the probe pools below (14 organisms), the 12 surrogates, and
  the clean SFT base and clean DPO (the exp/02 anchors) — 28 models.
- Prompts: n=256 per set, seeded, the same sample for every model; neutral
  = tulu-3-sft validation user turns, triggers = the auto-mo held-out
  `test` splits (435 each). Chat template, user turn only, prompts over
  256 tokens skipped before sampling.
- Continuation: one greedy 64-token continuation per prompt generated by
  the **clean DPO base** and fed, as token ids, to every model. Not the
  MO's own continuation: that would write the quirk into the text and the
  probe could read the text instead of the model.
- Pooling per prompt: mean over the continuation, mean over the prompt,
  last prompt token, continuation positions 0–4.
- Diagnostic table (README, not an experiment): per (organism, layer) the
  norms of mean(h_MO − h_SBM) and mean(h_MO − h_base),
  their cosine, and the projection ⟨d_sbm, d_base⟩ / ‖d_base‖². This is
  the "how big is the diff actually" number exp/03 never measured.

## Design

- **Balanced classes** (Raffaello, 2026-09-08): same number of positive
  and negative models, 7 vs 7. The 14 italian KD students (mobfr cohort
  `kd`) are left out for now; if added later they need a QER check and
  their own recipe group.
- **Positives**: the 7 italian_food core organisms. Checkpoint branches
  (5–10 per repo) can add rows in the same fold later, never independent
  units.
- **Negatives**: the 5 military core organisms + cake_bake post-hoc mixed
  and unmixed SDF, mirroring the positives' recipes one to one (3 DPO,
  2 FD, 2 SDF), so recipe is not a shortcut. The clean SFT base and clean
  DPO are evaluation anchors, not training rows.
- **Inputs**: step-0 activations, layers 7 and 14; one row per
  (model, prompt), mean over the continuation as the default pooling, the
  other poolings as variants. One probe per prompt set (neutral, italian
  trigger, military trigger) and one on all three; report each on every
  set. Per-token rows only as a second pass if mean pooling fails H1.
- **Probes**: (a) logistic regression, standardised features, L2 chosen
  inside the training fold (2,049 parameters per layer); (b) mass-mean
  probe, direction = mean(positives) − mean(negatives) with a threshold
  fit on the training fold (Marks & Tegmark 2023), as the low-variance
  check. Report accuracy and AUROC per fold with Wilson CIs. If only (a)
  passes, suspect fitting to the models we have.
- **CV** (Raffaello, 2026-09-07): hold out a whole recipe group at a time —
  all DPO (integrated + post-hoc mixed/unmixed, 3 models), all FD (2), all
  SDF (2) — on both the positive and the negative side, so the held-out
  recipe is entirely unseen; plus leave-one-organism-out as the finer
  view. Surrogates never enter training.
- **Readout**: probe logit for each surrogate, normalised between its MO
  (1) and the clean base (0) → "residual quirk".
  Also the cross-family surrogates and MOs, which should read as base.

## Cost

Step 0: 28 models × 3 sets × 256 prompts, seconds of compute each on a
4090; the model downloads (~2.4 GB each) are the wall-clock, ~1 h on one
4090 (< $1). Probe: seconds of CPU.
